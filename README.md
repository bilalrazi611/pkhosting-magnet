# PKHosting – Website Launch Checklist (Lead Magnet)

**Task:** Create a free tool or checklist as a lead magnet  
**Brand:** PKHosting.com

## What is included

1. **Website Launch Checklist PDF**  
   A professional, printable checklist covering:
   - Domain & Hosting
   - Website Content & Structure
   - Technical Checks
   - Security & Backups
   - SEO Basics
   - Final Pre-Launch steps

2. **Landing Page** (`landing-page/index.html`)  
   A clean, mobile-friendly page that:
   - Offers the checklist in exchange for an email address
   - Shows a thank-you message + download button after form submission
   - Can be connected to any email marketing tool later (Mailchimp, ConvertKit, etc.)

## How to use

### Option A – Simple local demo
1. Open `landing-page/index.html` in any browser
2. Enter an email and click the button
3. Download the PDF

### Option B – Host it
Upload the `landing-page` folder + the PDF to any web hosting (including PKHosting) and point a subdomain or page to it.
